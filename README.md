AdMobKit is a lightweight and easy-to-use Swift package for integrating Google AdMob in your iOS apps. It provides a clean, Swift-friendly API to handle:

Banner ads
Interstitial ads
Rewarded ads
Native ads
AppOpen ads

Features
 Easy integration via Swift Package Manager
 Fully SwiftUI & UIKit compatible
 Automatic ad loading & caching
 Minimal setup, maximum control

Installation

Swift Package Manager
